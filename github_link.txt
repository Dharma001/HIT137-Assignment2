# HIT137 Group Assignment 2

## 📌 Overview
This project implements a custom text encryption and decryption system using Python.

## ⚙️ Features
- File-based encryption
- Custom shifting algorithm
- Decryption and verification
- Modular code design

## 🧠 Encryption Rules
- a–m → forward shift (shift1 * shift2)
- n–z → backward shift (shift1 + shift2)
- A–M → backward shift (shift1)
- N–Z → forward shift (shift2²)
- Others unchanged
