# HIT137 Group Assignment 2

## 📌 Overview

This project is developed for HIT137 Group Assignment 2. It contains two main tasks:

### 🔹 Question 1: Text Encryption & Decryption

A Python program that:

- Reads text from `raw_text.txt`
- Encrypts it using custom shifting rules
- Writes output to `encrypted_text.txt`
- Decrypts it back
- Verifies correctness

### 🔹 Question 2: Expression Parser

A recursive descent parser that:

- Tokenizes mathematical expressions
- Builds an expression tree
- Evaluates expressions
- Handles errors (invalid input, divide by zero, etc.)

---

## ⚙️ Features

### Question 1

- File handling (read/write)
- Custom encryption rules:
  - Lowercase (a–m, n–z)
  - Uppercase (A–M, N–Z)
- Decryption function
- Verification system

### Question 2

- Tokenization of expressions
- Recursive descent parser
- Operator precedence handling
- Unary minus support (--5, -(3+4))
- Error handling
